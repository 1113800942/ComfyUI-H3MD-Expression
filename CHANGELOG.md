# Changelog

## 0.8.0 — 2026-11-24 — first public release

- Expression Studio node: load a picture, pick from the expression library or shape the face with sliders grouped by face part, copy an expression from a short video, play the 39-frame clip.
- 22 built-in expressions (13 kinds, one or two styles each); your own expressions saved to the library; rename / delete any expression, restore deleted built-ins.
- Export image: any frame of the clip as a PNG — whole picture at full size, or face only (512 × 512).
- Save character + expression: makes the H3 RefMod and shows the prompt line with a Copy button; Whole set makes every library expression for one character.
- Built-in face engine: LivePortrait networks (Kuaishou, MIT) + OpenCV YuNet face detection (MIT). No other ComfyUI plugin and no extra pip packages needed.
- Interface in English and Chinese, following ComfyUI's language setting.
